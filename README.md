# Bellabeat Smart Device Case Study – Sarjo Manneh

This case study analyzes smart device usage data to uncover user behavior trends. The goal is to support **Bellabeat’s marketing strategy** by exploring how women interact with wellness trackers and identifying actionable insights.

The project includes data cleaning, SQL-based processing, and data visualization using **Excel**, **SQLite**, and **Tableau**.
